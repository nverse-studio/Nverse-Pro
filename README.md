# Nverse-Pro

基于 Android 底层与 Shizuku 授权的工具。

## 1. 项目简介

Nverse-Pro 是由中国独立开发者 南辞 (Nanci) 发起并开发的开源项目。它主要依赖 Shizuku 框架作为底层权限分发桥梁，致力于为 Android 极客玩家提供免 Root 的系统级调教与自动化工具。本项目致力于探索 Android 系统的深度定制与底层权限管理的安全边界，将复杂的 Shell 指令与系统级 API 调用封装为直观的用户界面，降低高级系统操作的门槛。

## 2. 核心功能

### 2.1 系统底层与权限
- 谷歌三件套安装：一键静默部署 GMS 核心服务，解决原生系统缺失问题。
- 分发 APP ADB 权限：深度集成自研框架，实现应用级权限安全分发，允许其他应用通过授权获取受控的 Shell 权限。
- 专属底层启动：支持无线调试、Root 及电脑启动动画，动画逻辑受月虹提权助手启发并进行了深度重构与定制。
- 一键临时 Root：获取临时 Root 权限，重启即失效。针对华为及荣耀部分受限机型进行了专项适配。

### 2.2 极客进阶操作
- 一键修改底层系统：涉及系统分区挂载与核心参数修改，仅限已越狱（Jailbreak）设备执行，普通设备强锁不可用。
- 一键下载海外应用：内置海外节点加速能力，支持直接拉取并安装海外优质应用。

### 2.3 网络安全与 AI 审核
- 安全读取网页源码：内置 AI 自动审核机制。在抓取目标网页源码前，系统会通过 AI 接口进行安全合规性审查，严格禁止非法盗用商业网站数据，仅限个人小站或开源项目使用。

## 3. 技术栈

- 开发语言：Kotlin
- UI 架构：Jetpack Compose (Material 3)
- 核心依赖：Shizuku API, Kotlin Coroutines
- 最低兼容：Android 8.0 (API 26)

## 4. 编译与运行环境

本项目基于 Android Studio 开发，推荐使用最新稳定版的 Gradle 进行构建。在编译前，请确保本地环境已正确配置 Android SDK (API 33) 以及 Kotlin 编译器。由于涉及 Shizuku 权限调用，请确保在运行设备上已正确安装并激活 Shizuku 服务端。
